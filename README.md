Hi, this is an unfinished version 1 of the candy laucher, currently only tested on my laptop(hp victus).
to try out:
laptop must have OMEN Gaming Hub key on keyboard(phisical key)

install the python script and set to run on start in windows

upload the esp code to the ai thinker esp32 board

press OMEN key to enter a livestream mode where the python script shows a box around your mouth.

as i said this is still an early prototype and movement, inverse kinematics, and lauching actual candy is not funcional yet
